# sibsutis-schedule-bot

## Telegram-бот расписания **СибГУТИ**


Показывает текущую пару, расписание на день и календарь на месяц, с учетом выбранной группы

Фактически бот копирует расписание с сайта, давая студентам возможность получать информацию в удобном для них виде

## Возможности

- **Сейчас** (`/now`) — какая пара идёт, сколько осталось, что дальше
- **Сегодня / Завтра** (`/today`, `/tomorrow`) — расписание на день с навигацией по дням
- **Месяц** — календарь с учебными днями и навигацией по месяцам
- **Выбор группы** — поиск своей группы
- **Настройки** (`/settings`) — смена группы
- **Аналитика** (`/stats`) — статистика использования для админов
