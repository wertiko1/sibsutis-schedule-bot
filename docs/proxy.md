# Прокси

## Зачем нужен прокси

Сайт СибГУТИ (`sibsutis.ru`) принимает запросы только с российских IP-адресов. При этом серверы Telegram, на которых работает бот, находятся за пределами РФ. Без прокси бот не сможет получить расписание с сайта.

**Решение** — SOCKS5-прокси с российским IP, через который бот обращается к `sibsutis.ru`.

## Настройка

В `.env` указать переменную:

```env
SIBSUTIS_PROXY_URL=socks5://user:password@host:port
```

Если переменная не задана — прокси не используется и бот обращается к сайту напрямую.

## Где взять прокси

Подойдёт любой SOCKS5-прокси с российским IP. Варианты:

- Свой VPS/VPN в РФ
- Коммерческие прокси-сервисы
